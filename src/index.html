iOS Installation Guide

Please note that for this guide you'll need a computer and a cable to connect your iPhone to it.
If you see "App no longer available" after 7 days, reconnect your phone and repeat the installation via Sideloadly to refresh the license.
1

Downloading IPA to PC

Go to the channel where we store download files: t.me/talefiles. Find the file that ends with .ipa and download it.

2

Sideloadly Installation to PC

  • Go to sideloadly.io and click Download. Open the .exe file and set it up.
  • Open Sideloadly.
  • Connect your iPhone via USB.
  • Select the downloaded .ipa file.
  • Enter your Apple ID and sign in.
  • Click Start to begin.
3

Finishing Installation

On your iPhone you need to enable Developer Mode before launching.

Open Settings → Privacy & Security → Developer Mode, toggle it On and restart.

After restarting, open Settings → General → VPN & Device Management, select the profile associated with your Apple ID, tap Trust and confirm. The app will now launch.

Troubleshooting & Error Fixes

If Sideloadly shows "No device selected", install the correct drivers:

  1. Download 3uTools
  2. Install and open.
  3. Click Repair Drivers.
  4. Re-open Sideloadly.

"Login Failed" means a wrong Apple ID password. Reset it on your iPhone:

  1. Settings → your name → Sign-In & Security.
  2. Tap Change Password and follow the steps.

An Xcode error means Parental Controls are enabled. Create a new Apple ID with age over 18:

  1. Settings → your name → Sign Out.
  2. Sign in → Create new Apple ID → set birth date over 18.

Buying Certificate

Go to applep12.com or another private certificate provider and buy one. After purchasing the certificate, save the .p12, .mobileprovision, and password files provided to you (AppleP12 sends these files by email).

2

Installation

  1. Go to the @ipasignx bot on Telegram.
  2. Type /start, tap Manage Certs, and then tap Add P12.
  3. The bot will ask you for the required files. Send them one by one in the requested order.
  4. Once the certificate has been added successfully, type /start again and tap the Sign IPA button.
  5. Send the Tale Stars IPA file to the bot (you can directly forward it from the @talefiles channel). The process may take a few minutes. When the menu appears, tap Start Signing.
  6. After a few more minutes, open the link provided by the bot in Safari to install the game.

This website is open source

The TaleMods website (not the mods or the products) is open source. The front end lives on GitHub, so anyone can read the code, report issues, and help make it better. Pick an area below to get started.

View on GitHub

Ways to contribute

Code

The site is plain HTML, CSS and JavaScript, with no framework and no build step. Fork the repository, make your change, and open a pull request. Bug fixes, performance tweaks, and new sections are all welcome.

Design

Got an idea to make the interface better? Open an issue with a screenshot or mockup, or send a pull request.

Translate

Translations are simple JSON files in the i18n folder. To add a language, copy en.json, translate the values, and register it in languages.json. To fix an existing translation, just edit that language's file and open a pull request.
